# ZhuZhu Stroke Data

Stroke-order data is derived from Make Me a Hanzi (github.com/skishore/makemeahanzi), which is derived from the fonts AR PL KaitiM GB and AR PL UKai, Copyright 1999 Arphic Technology Co., Ltd. Used and redistributed under the Arphic Public License; the full licence text is included. ZhuZhu's modified copy (only the characters the app uses, converted to JSON) is freely available at: https://github.com/orgred-org/zhuzhu-stroke-data.

## Contents

- `hsk1.json`: Stroke outlines and centre lines ("medians") in writing order for the 248 Simplified Chinese characters used by HSK 1 in the ZhuZhu app, converted to JSON.
- `APL/`: The Arphic Public License folder from the upstream repository, kept unchanged.

## Source and changes

- Upstream source: `graphics.txt` from [Make Me a Hanzi](https://github.com/skishore/makemeahanzi) at commit `bddc96d41bef78427ed0e034e9f7e31d71fd1b92`.
- Each data file's `notice` field states how and when it was changed from the upstream file.
